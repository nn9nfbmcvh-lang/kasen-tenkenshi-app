# 河川点検士アプリ Ver.1.0

河川点検の着眼点を、写真・知識問題で学ぶためのモバイル対応Webアプリです。インストール可能なPWAとして動作し、一度読み込んだ後はオフラインでも利用できます。

公開URL（変更禁止）
https://nn9nfbmcvh-lang.github.io/kasen-tenkenshi-app/

## Ver.1.0 の機能

- 全300問
  - 写真問題 165問（選定済み写真55枚を3つの着眼点で使用）
  - イラスト問題 0問
  - 知識問題 135問
- 全問に分野、中分類、小分類、5段階難易度、想定出題傾向、復習優先度、キーワード、詳細解説、関連問題を収録
- 試験モード
  - 300問からランダム50問
  - 制限時間90分
  - 試験中は正誤・正解色・解説を表示しない
  - 前へ戻る、問題一覧、後で見直す、未回答確認
  - 終了後に採点し、全問の正答・解説を確認可能
  - 誤答・未回答だけを再出題
- 学習モード
  - 分野別
  - 未回答だけ
  - 写真だけ
  - 法令だけ
  - Sランクだけ
  - 難問だけ
  - 想定出題傾向90%以上だけ
- 学習履歴と見直しリストを端末内に保存
- 100問版の問題IDと保存キーを維持し、正解・誤答を含む回答済み記録を引き継ぐ
- パスワード入力後の起動演出（初期パスワード: `4151`）
- 「学習を終了」後の終了演出
- 学習モードでは選択後に「回答を表示」を押したときだけ正誤を表示
- iPhoneのホーム画面追加、セーフエリア、スタンドアロン表示に対応
- Service Workerによるオフライン利用

## ローカル起動

ビルド工程や外部依存はありません。リポジトリ直下をHTTPサーバーで配信します。

```powershell
python -m http.server 4173
```

`http://127.0.0.1:4173/` をブラウザで開いてください。Service Workerは `file://` では動作しません。

## 問題データ

100問版の実写真問題は `photo-questions.js`、AI参考写真・知識問題は `questions.js`、追加200問は `extended-questions.js` に格納しています。各問題は次の項目を持ちます。

```text
id / number / type / question / choices / answer / explanation
field / middle / small / difficulty / trend / priority
keywords / related / scene
```

問題数と必須項目は次のコマンドで検証できます。

```powershell
node tests/validate-questions.js
```

## 写真の出典

使用する55枚のうち実写真40枚は、国土交通省「堤防等河川管理施設及び河道の点検・評価要領 参考資料」の事例写真を、表示用にサイズ・圧縮率を調整して使用しています。追加の15枚は問題文から推定して作成したAI参考写真で、アプリ画面上でもその旨を明記しています。300問版では、同じ写真を変状判別・計測・経年比較・初動対応など3つの異なる着眼点で学習します。

- 出典：[国土交通省「堤防等河川管理施設及び河道の点検・評価要領 参考資料」](https://www.mlit.go.jp/river/shishin_guideline/kasen/pdf/08_teiboukadou_tenkenkekka_sankou.pdf)
- 技術基準：[国土交通省「河川砂防技術基準 維持管理編（河川編）」](https://www.mlit.go.jp/river/shishin_guideline/gijutsu/gijutsukijunn/ijikanri/kasen/pdf/ijikanri_kasen_all_2025.pdf)
- 利用条件：[国土交通省 リンク・著作権・免責事項](https://www.mlit.go.jp/link.html)
- 各写真の出典ページは、アプリの写真直下に表示しています。

写真の抽出は `tools/extract-mlit-photos.py` で再現できます。元PDFはリポジトリへ含めません。
